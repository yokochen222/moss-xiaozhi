74HC595D (U2) — FM 显示驱动型（非 TI/NXP 标准脚位）

MCU:
  SER (14) = GPIO21
  RCK (12) = GPIO47  — 手册：高电平存储
  SCK (11) = GPIO48  — 手册：上升沿移位
  VDD (16) = 3V3
  GND (8)  = GND

【与标准 595 的差异 — 以 FM 手册为准】
  Pin10、Pin13 = NC（悬空脚），原理图标 NC 正确
  无 /OE、无 /MR；输出常使能，不靠这两脚控制
  驱动必须在 RCK 锁存脉冲后拉回低电平，避免“高电平存储”窗口常开
    → 空闲噪声改写 Qx → ULN 误导通 → 停转线圈发烫

上电：板级构造末尾调用 StepperGimbalDevice::Stop() 写全 0。
停转：Move 结束 / stop / 强杀任务后均写全 0（写两次防半截移位）。

Q 网络（原理图）：
  Q0=M2_L4  Q1=M1_L1  Q2=M1_L2  Q3=M1_L3
  Q4=M1_L4  Q5=M2_L1  Q6=M2_L2  Q7=M2_L3

轴分配（软件）：
  左右 M2: A=Q5 B=Q6 C=Q7 D=Q0
  上下 M1: A=Q1 B=Q2 C=Q3 D=Q4

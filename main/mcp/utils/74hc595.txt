74HC595引脚连接图：

VCC (16) -------- 3.3V电源
GND (8)  -------- 地线
SER (14) -------- GPIO9 (数据输入)
RCK (12) -------- GPIO10 (锁存时钟)
SCK (11) -------- GPIO11 (移位时钟)
OE (13)  -------- 地线 (输出使能，低电平有效)
MR (10)  -------- 3.3V (主复位，高电平有效)
Q0 (15)  -------- LED0 + 限流电阻(220Ω) + 地线
Q1 (1)   -------- LED1 + 限流电阻(220Ω) + 地线
Q2 (2)   -------- LED2 + 限流电阻(220Ω) + 地线
Q3 (3)   -------- LED3 + 限流电阻(220Ω) + 地线
Q4 (4)   -------- LED4 + 限流电阻(220Ω) + 地线
Q5 (5)   -------- 面板灯1 + 限流电阻(220Ω) + 地线
Q6 (6)   -------- 面板灯2 + 限流电阻(220Ω) + 地线
Q7 (7)   -------- 底灯   + 限流电阻(220Ω) + 地线

说明（2026-07-09 更新）：
- Q0-Q4 由 LampBarDevice 控制，做流水灯效果。
- Q5-Q7 由 LampPanelDevice 控制，做前面板灯x2 与底灯（均常亮、无流水动画）。
- 流水灯与面板灯/底灯共用同一组 SER/RCK/SCK 引脚、同一颗 74HC595。
- 互不影响机制（驱动层保证）：
  * ShiftRegister74HC595 内置一个共享静态成员 panel_state_ 维护 Q5-Q7 的"事实来源"。
  * SetOutputs() 在写入时自动用 panel_state_ 覆盖高 3 位 —— 流水灯 (Q0-Q4)
    每次刷新都会"捎带"当前面板/底灯状态，流水灯无论运行/停止都不会冲掉面板/底灯。
  * SetPanelBit() 是面板/底灯专用通道 —— 写完后立即把合并后的 8 位
    (Q0-Q4 流水灯当前值 + Q5-Q7 面板/底灯当前值) 锁存到硬件，
    面板/底灯的开关也不会打断流水灯。
  * ClearAll()/Reset() 只清低 5 位 (Q0-Q4)，保留 Q5-Q7。
- 结果：流水灯与面板/底灯可同时运行、互不感知、互不干扰。
